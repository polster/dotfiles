== Intro

=== Description

Contains `dotfile` configurations and scripts, used to setup my local base dev env.

[NOTE]
This setup is tailored to my own needs, so use at your own risk.

=== Prerequisites

* MacOS (Apple Silicon)
* link:https://brew.sh/[Home brew]
* pre-commit

== Get started

* Git clone this repo and `cd` into it
[source,bash]
----
git clone git@github.com:polster/dotfiles.git $HOME/dotfiles
----

* To enable pre-commit hooks for this repo:
[source,bash]
----
make pre-commit-install
----

* Run the following commands:
[source,bash]
----
# Install packages
brew bundle

# Install oh-my-zsh
make package-install-zsh

# Install sdkman
make package-install-sdkman

# Install dotfiles
make dotfiles-install
----

== Hints

=== Command line tools

Starting from scratch, or even after a MacOS version upgrade, it may happen that tools like `git` require installing the `command line tools`. This to be done easily with the following command:

[source,bash]
----
xcode-select --install
----

=== VSCode extensions

To manage extensions in `VSCode`, the following commands are available:
[source,bash]
----
# Install extensions
make vscode-extensions-install

# Dump from existing setup
make vscode-extensions-dump
----

=== VSCode settings

Shared settings live in `vscode/settings.json`. Private settings (e.g. `github-enterprise.uris`) belong in
`~/.config/vscode/settings.local.json`, which is not committed. Override the location with `VSCODE_LOCAL_SETTINGS`.
Both files are merged with `jq`, local values taking precedence, and must be plain JSON (no comments).
[source,bash]
----
# Write merged settings into VSCode (a .bak copy of the previous file is kept)
make vscode-settings-install

# Show differences between merged and current VSCode settings
make vscode-settings-diff
----

Changes made via the VSCode UI are not synced back; copy them into the appropriate file.
If VSCode Settings Sync is enabled, consider disabling settings sync to avoid conflicts.

=== PlantUML server

A local `plantuml-server:jetty` instance is available on `http://localhost:39854`, used by the `jebbs.plantuml` extension.
[source,bash]
----
make vscode-compose-start
make vscode-compose-stop
make vscode-compose-restart
make vscode-compose-status
make vscode-compose-logs
----

=== Docker CLI emulation with Podman

To maintain backward compatibility with familiar Docker commands, the following make commands are available:
[source,bash]
----
# Install emulation
make podman-docker-emulation-install

# Remove emulation
make podman-docker-emulation-remove
----

Validation:
[source,bash]
----
docker run -it docker.io/hello-world
----

=== Switching between apps like on Windows

For those folks missing the way how to `ALT-Tab` between applications like on Windows, there is a tool for that :-)

Installed automatically with this setup, comes link:https://alt-tab-macos.netlify.app/[alt-tab]. Once started, just hit `Option+Tab`.

=== Advanced window manager

Especially new people to MacOS are not comfortable with the OS functionality application windows can be arranged and resized. Also here, there is a tool for that: link:https://rectangleapp.com/[rectangle]

Installed automatically with this setup, check their user documentation how to use it in detail.

=== Uninstall everything

In case you need to remove everything installed by `brew`, the following one-liner will do the job (beware):
[source,bash]
----
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/uninstall.sh)"
----
